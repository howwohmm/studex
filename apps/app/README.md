# apps/app — Studex universal app

Expo SDK 57 · Expo Router · React Native 0.86 · React 19 · Reanimated 4. One codebase for iOS,
Android and Web (ADR-002). Read the SDK 57 docs before changing code:
https://docs.expo.dev/versions/v57.0.0/

Run everything from the repository root (`pnpm dev`, `pnpm web`, `pnpm ios`, `pnpm android`).
Native device builds run from this folder: `npx expo run:ios --device`,
`eas build --profile development --platform android`.
