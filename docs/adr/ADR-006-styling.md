# ADR-006: Styling
- Status: Accepted
- Date: 2026-11-20 · Deciders: lead agent, Ohm
- Spec links: `docs/spec/06-architecture.md` §2 (ADR-006)

## Context
Fewest compatibility risks on SDK 57; full control of a distinctive design.

## Decision
Styling: React Native StyleSheet + typed tokens (`packages/ui`); Reanimated 4, Gesture Handler, expo-haptics, FlashList; native sheets via Expo Router presentation. No UI-kit or CSS-in-JS dependency.

## Evidence
Decided in the master spec on 2026-11-20; no spike required.

## Consequences
To be completed when the decision is exercised (first ticket that depends on it).

## Fallback / exit plan
See the spec row; a change requires a new ADR approved by the lead and Ohm.
