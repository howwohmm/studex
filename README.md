# Studex

Studex is the daily academic companion for Indian college students.

It answers one question every morning: **What do I have today?**

→ timetable parser (photo/PDF → Claude extracts everything)  
→ subject folders  
→ bunk tracker that applies the 75% rule

**Status:** pre-launch · 10 confirmed early users · Udyam registered

## Run the web preview

Use Node.js 22.12 or newer. No sign-in or API key is needed.

```sh
cd apps/web
npm ci
npm run dev
```

Open the URL printed by Vite. Try the example workspace, or use **Settings → Start my own workspace** to create a blank one. See the [web app guide](apps/web/README.md) for import formats, tests, and scope.
